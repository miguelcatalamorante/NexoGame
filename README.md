# 🧟 NexoGame

Videojuego de supervivencia contra zombis desarrollado en **Unity y C#** como proyecto personal.

El proyecto nace con el objetivo de poner en práctica el desarrollo de videojuegos, programación orientada a objetos y creación de diferentes sistemas de gameplay utilizando Unity.

## 🎮 Sobre el proyecto

NexoGame es un videojuego de acción y supervivencia en el que el jugador debe enfrentarse a zombis utilizando diferentes armas y gestionar sus recursos para sobrevivir
las maximas rondas posibles.

El proyecto incluye diferentes mecánicas y sistemas desarrollados desde cero durante el proceso de aprendizaje.

## ⚙️ Características

- 🧟 Sistema de enemigos y zombis
- 🔫 Sistema de armas
- 🎒 Inventario
- 🔄 Sistema de recarga
- 🔢 HUD y contador de munición
- ❤️ Sistema de vida
- 🏃 Movimiento y control del jugador
- ⚡ Sistema de estamina
- 🎯 Ataques y comportamiento de enemigos
- 🗺️ Mapa y escenario jugable
- 🎮 Menú principal
- 💀 Sistema de Game Over
- 🎬 Animaciones del personaje

## 🛠️ Tecnologías utilizadas

## 📂 Estructura del proyecto

El proyecto sigue la estructura estándar de Unity:

- `Assets/` → Scripts, escenas, modelos, animaciones y recursos.
- `Packages/` → Dependencias utilizadas por Unity.
- `ProjectSettings/` → Configuración del proyecto.

Los archivos temporales generados por Unity y Visual Studio están excluidos mediante `.gitignore`.
